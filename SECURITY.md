# Security Policy

If you discover a security vulnerability in Poncho Admin Bundle, please **do not** open a public issue.

Instead, report it privately via GitHub's [security advisory form](https://github.com/beaumu/poncho-admin-bundle/security/advisories/new).

Include the affected versions, what an attacker can do and what they need first, and the steps to
reproduce. The fix is prepared privately and released for every maintained branch together with
the advisory; you are credited unless you prefer not to be. See
[Security issues](https://beaumu.github.io/poncho-admin-bundle/#/contributing/security) for the
full process, and [Security](https://beaumu.github.io/poncho-admin-bundle/#/security) for hardening
an application.
