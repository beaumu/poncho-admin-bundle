# Contributing

Thank you for considering contributing to Poncho Admin Bundle!

The process mirrors Symfony's: fork the repository, work in a topic branch, and open a pull request
with the filled-in PR table. The full guide is in the documentation:

- [Contributing overview](https://beaumu.github.io/poncho-admin-bundle/#/contributing/index)
- [Reporting a bug](https://beaumu.github.io/poncho-admin-bundle/#/contributing/bugs)
- [Submitting a patch](https://beaumu.github.io/poncho-admin-bundle/#/contributing/pull_requests)
- [Coding standards](https://beaumu.github.io/poncho-admin-bundle/#/contributing/standards)
- [Backward compatibility promise](https://beaumu.github.io/poncho-admin-bundle/#/contributing/bc)
  and [deprecations](https://beaumu.github.io/poncho-admin-bundle/#/contributing/deprecations)

The same pages are in [`docs/contributing/`](docs/contributing/index.md).

**Security issues** are never reported publicly — see [SECURITY.md](SECURITY.md).
